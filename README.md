# Zootopia World

주토피아와 디즈니+를 소개하는 반응형 정적 멀티페이지 홈페이지입니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 모든 파일을 저장소의 최상위에 업로드합니다.
3. 저장소 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 설정하고, `main` 브랜치의 `/(root)`를 선택합니다.
4. 저장하면 안내되는 주소에서 사이트를 확인할 수 있습니다.

## 구성

- `index.html` — 홈
- `zootopia.html` — 주토피아 소개
- `disney.html` — 디즈니 소개
- `zootopia-poster.png` — 제공받은 포스터 이미지 (최상위 폴더에 반드시 함께 업로드)
